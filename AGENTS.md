# Codex rules

- Never commit directly to `main`.
- Create a dedicated branch for each task.
- Never store credentials, tokens, private keys, or production secrets in Git.
- Never access or deploy to production unless the user explicitly authorizes it.
- Do not modify infrastructure outside this repository unless explicitly requested.
- Run relevant tests, linting, and builds before proposing a merge.
- Present the resulting diff and validation results before merging to `main`.
- Never force-push `main`.
